# cherri

A modern web application built with advanced frontend technologies.

## Features

- Single-page application architecture
- Service worker support for offline functionality
- Advanced routing with Riptide and Sapphire routers
- Scramjet integration for enhanced performance
- Responsive design with modern UI components
- Extensive emoji and profile decoration elements

## Technologies

- React (bundled)
- Service Workers
- IndexedDB for local storage
- WebAssembly (via Scramjet)
- Custom routing systems

## Deployment

This site is designed to be deployed as a static site. The `_redirects` file handles routing for single-page application compatibility.
